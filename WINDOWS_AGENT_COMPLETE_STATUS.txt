5. HOW THE SYSTEM WORKS
═══════════════════════════════════════════════════════════════════════════════

   POLLING CYCLE (every 15 seconds):
   
   1. Agent queries Windows Event Log (System + Application)
      └─ Get all events with RecordId > last_tracked_id
      
   2. For each new event:
      └─ Extract: Event ID, Provider/Source, Timestamp, Message
      └─ Determine severity (Info, Warning, Error)
      └─ Create JSON payload
      
   3. HTTP POST to Laravel API
      └─ URL: http://127.0.0.1:8000/api/agent/logs
      └─ Header: X-Agent-Token: some-long-random-secret
      └─ Body: JSON with event data
      
   4. Laravel processes event:
      └─ Validates authentication token ✓
      └─ Stores in database (server_logs table) ✓
      └─ Auto-classifies by severity ✓
      └─ Triggers alerts if Critical/Emergency ✓
      
   5. Agent updates state.json
      └─ Records new highest RecordIds
      └─ Prevents duplicate submissions
      
   VERIFICATION: Last test log (ID: 895) accepted at 2026-05-04 17:30
